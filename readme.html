# Kazibwe Foundation School Website – Project Summary ## Project Overview This project is a school website developed using the WordPress framework. It provides information about Kazibwe Foundation School, its learning programmes, activities, and contact details. ## Website Pages The website includes the following pages: - Home:Introduction to the school and its main activities. - About: Background and information about the school. - Academics:* Details of academic programmes and learning activities. - Gallery: Photographs showing school facilities, learning, and extracurricular activities. - Contact: School contact information and an online contact form. - Enroll:* Information for parents interested in enrolling their children. ## Website Images and Media The project includes images used across the website, covering classroom activities, school facilities, early learning, literacy, sports, singing, debates, and other school activities. ## Main Features - WordPress-based website structure. - Responsive website layout for desktop and mobile devices. - School information and academic content. - Image gallery. - Contact form with a thank-you page after submission. - Navigation between the main website pages. ## Project Files The GitHub repository contains the WordPress website files, including the website theme, pages, images, and other required project resources. The exported MySQL database will also be included in the `sql` folder to preserve the website content and database structure. ## Purpose The project demonstrates the design and development of a school website using WordPress. It is submitted through GitHub as part of the website design assignment.
